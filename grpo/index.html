GRPO 一步训练：Countdown 题 [42, 32, 5] → 50

本质上是，策略模型对同一道题写一组回答，奖励函数给每个回答判分，判分比这组平均高的回答，每个 token 都被推高，比平均低的，每个 token 都被压低。

优势怎么算：一组回答的平均和标准差

本质上是，每个回答的判分减去这组回答的平均判分，再除以这组判分的标准差，得到的数就是这个回答里每个 token 的优势。

策略怎么更新：比率、截断和 KL

本质上是，和 PPO 一样，拿现在的策略模型和写回答时的策略模型比，同一个 token 的概率变成了几倍，按优势推这个倍数，倍数一超出 0.8 到 1.2 就不再往有利方向推；设了 beta 时，再把离参考模型的 KL 加进损失。
