DPO 一步训练：Countdown 题 [42, 32, 5] → 50

本质上是，对同一道题的一对回答，策略模型和参考模型各给每个回答算一个 logp，策略模型比参考模型越偏向 chosen 回答、越远离 rejected 回答，损失就越小。

回答的 logp 怎么算：每个 token 的 logp 加起来

本质上是，模型给回答里每个 token 算一个 logp，把这些 logp 加起来，就是整个回答的 logp。

损失怎么算：隐式奖励、margin 和 −ln σ

本质上是，chosen 回答的 logp 差减 rejected 回答的 logp 差，乘以 β 得到 margin，margin 越大损失越小，大到一定程度就几乎不再推。

为什么不需要奖励模型：从 PPO 的目标推出 DPO 的损失

本质上是，PPO 要找的最好的策略模型可以反过来写出奖励：奖励 = β × ln(策略模型的概率 ÷ 参考模型的概率) + 一个只和题目有关的数，两个回答一相减，这个数就消掉了。
