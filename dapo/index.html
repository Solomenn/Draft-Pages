DAPO 一步训练：Countdown 题 [42, 32, 5] → 50

本质上是，DAPO 照 GRPO 让模型对一道题写一组回答、比这组平均好的回答推高、比平均差的压低，再改掉 GRPO 里让训练学不动的 4 处，并且不加 KL。

Overlong Reward Shaping：回答太长就扣分

本质上是，回答写得快到长度上限时，越长扣分越多；写到上限还没写完的回答，可以整个不算进损失。

Dynamic Sampling：丢掉死组，再拿新题补满

本质上是，一道题的一组回答全对或全错，就整组扔掉，再让模型拿新题写回答，直到这一批里每道题的回答都有对有错。

Clip-Higher：截断上限从 1.2 放宽到 1.28

本质上是，优势为正的 token 一次最多能涨到原来概率的 1.28 倍而不是 1.2 倍，原本很少写的 token 因此能多涨一点。

Token-Level Loss：损失除以全部 token 的个数

本质上是，一批里每个 token 的损失分量一样重，长回答有多少个 token 就占多少份，不再和短回答各占一份。
