一条轨迹怎么来：修代码任务

本质上是，策略模型每次只写一个工具调用，环境执行后把结果接到后面，策略模型接着写，直到写出 finish；轨迹写完后，环境重新跑测试，给整条轨迹一个判分。

哪些 token 参与训练：loss mask

本质上是，一条轨迹里只有策略模型自己写的 token 算损失，题目和环境返回的工具输出只给策略模型读，不算损失。

判分和优势：同一个任务写一组轨迹

本质上是，同一个任务写 4 条轨迹，每条的判分减去 4 条的平均判分、再除以标准差，就是这条轨迹的优势；这条轨迹里策略模型写的每个 token 都用这一个数。

策略模型怎么更新：损失怎么合成一个数

本质上是，策略模型写的每个 token 按优势被推高或压低，再把所有这些 token 的损失合成一个数；按 token 平均还是按轨迹平均，决定了长轨迹占多大分量。
