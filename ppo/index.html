PPO 一步训练：Countdown 题 [42, 32, 5] → 50

本质上是，策略模型先自己写一个回答，判分后把分数落到每个 token 上，比价值模型预计得好的 token 被调得更容易写出来、差的更不容易，而且每次只许改一小步。

奖励怎么落到每个 token 上：KL 惩罚加判分

本质上是，回答写完才能判分，所以判分只记在最后一个 token 上；每个 token 再按策略模型离参考模型多远扣一点分。

优势怎么算：价值模型和 GAE

本质上是，价值模型在写每个 token 之前先预计一个分，写完这个 token 后，拿到的加上新的预计比原来的预计多出多少，就是这个 token 的功劳；把后面几个 token 的功劳打折加进来，就是优势。

策略怎么更新：比率和截断

本质上是，拿现在的策略模型和写回答时的策略模型比，同一个 token 的概率变成了几倍；按优势把这个倍数往有利方向推，但倍数一超出 0.8 到 1.2 就不再推。
